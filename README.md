# Multi-Vendor-Marketplace

**_Backend_**

- Nodejs
- Mongodb
- Express

**_Frontend_**

- React Js

## Step to Start

**For Backend**

1.  `git clone https://github.com/MohitSojitra/e-commerce-store.git`
2.  `cd Multi-Vendor-Marketplace`
3.  `npm install`
4.  `npm run dev`

**For Frontend**

1.  `cd Multi-Vendor-Marketplace`
2.  `npm install`
3.  `npm run start`
