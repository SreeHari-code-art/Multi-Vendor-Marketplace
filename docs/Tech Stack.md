### Core Tech Stack

| Layer                | Technology                    | Role in Project                                                                                       |
| -------------------- | ----------------------------- | ----------------------------------------------------------------------------------------------------- |
| **Frontend UI**      | **React.js** + **HTML / CSS** | Component-driven single-page architecture for customer shopping flow, seller portal, and admin views. |
| **Styling & Layout** | **Bootstrap** + Custom CSS    | Rapid layout scaffolding, responsive navbar grids, tables for dashboards, and form controls.          |
| **State Management** | **Redux Toolkit (RTK)**       | Global tracking of customer authentication sessions, shopping cart items, and wishlist data.          |
| **Backend Runtime**  | **Node.js**                   | Asynchronous server runtime handling network connections and execution context.                       |
| **Web Framework**    | **Express.js**                | Lightweight routing structure, middleware orchestration, and REST API controller handling.            |
| **Database & ODM**   | **MongoDB & Mongoose**        | NoSQL document storage enforcing relational references via `ObjectId` links and schema validation.    |
